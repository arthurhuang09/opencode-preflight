# Security Policy

## Supported Versions

Security fixes are provided for the latest published npm version.

## Reporting A Vulnerability

Please report suspected vulnerabilities privately through GitHub Security Advisories when available:

https://github.com/arthurhuang09/opencode-preflight/security/advisories/new

If advisories are unavailable, open a GitHub issue with minimal public details and ask for a private disclosure channel. Do not include exploit details, secrets, or sensitive logs in a public issue.

## Scope

Relevant reports include issues that could expose secrets, run unintended commands, bypass user confirmation for preflight actions, or publish sensitive project-local preflight data.
